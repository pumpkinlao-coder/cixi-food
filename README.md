# 慈溪味 · 慈溪菜菜谱大全

一个纯静态的慈溪菜菜谱查询网站，收录 **561 道**慈溪与甬帮菜做法。

## 功能特性

- 🔍 关键词搜索（菜名、食材、标签）
- 🗂 8 大分类筛选（海鲜 / 河鲜 / 肉类佳肴 / 时蔬小炒 / 腌糟醉鲜 / 汤羹炖品 / 主食点心 / 甜品饮品）
- 🌿 **时令筛选**（春令 54 / 夏令 52 / 秋令 48 / 冬令 95，共 242 道时令性明确的菜）
- 📅 **本月时令**（首页自动按当前月份列出当令菜，230 道按月索引，1–12 月全覆盖；可直接跳到本季全部）
- 🏘 **乡镇筛选**（浒山、观海卫、鸣鹤、龙山、掌起、附海、逍林、新浦、胜山、桥头、匡堰、横河、坎墩、崇寿、长河、宗汉、周巷、庵东、白沙、三北，共 70 道出处可考的乡镇代表菜）
- 🏠 「外地可做」筛选（398 道食材通行的菜，人在外地也能照做）
- 📊 难度与用时排序
- 📖 点击菜卡查看完整材料清单与分步做法，**227 道菜含「做法二 / 做法三」变体**（同一食材的多种家常做法，弹窗内可切换）
- 🎲 「今天吃什么」随机推荐
- 🍽 一键点菜：按人数（2–12 人）与是否喝酒自动搭配一桌菜，冷菜先上，荤素均衡、主料不重复；结果可**一键复制成菜单文本**，直接发微信
- 📱 响应式布局，桌面 / 平板 / 手机均适配
- 🔗 深链直达（如 `#recipe-15`）

```

├── assets/
│   ├── app.js            # 应用逻辑（搜索/筛选/弹窗/图表/点菜交互）
│   ├── recipes-part1~14.js# 菜谱数据（共 561 道）

│   ├── town.js           # 乡镇索引（按菜名，70 条）
│   ├── month.js          # 月度时令索引（按菜名，230 条，1–12 月）
│   ├── order.js          # 一键点菜算法（冷菜/下酒菜标注 + 搭配逻辑）

│   ├── remote.js         # 「外地可做」标注

    ├── fonts/            # 本地字体
    └── js/echarts.min.js # 图表库
```

## 本地运行

纯静态网站，零依赖。双击 `cixi-recipes.html`，或启动本地服务器：

```bash
cd cixi-recipes
python3 -m http.server 8899
# 浏览器访问 http://localhost:8899/
```

## 技术栈

原生 HTML / CSS / JavaScript + ECharts（本地资源，无外网依赖）。
