# 慈溪味 · 慈溪菜菜谱大全

一个纯静态的慈溪菜菜谱查询网站，收录 **206 道**慈溪与甬帮菜做法。

## 功能特性

- 🔍 关键词搜索（菜名、食材、标签）
- 🗂 8 大分类筛选（海鲜 / 河鲜 / 肉类佳肴 / 时蔬小炒 / 腌糟醉鲜 / 汤羹炖品 / 主食点心 / 甜品饮品）
- 🏠 「外地可做」筛选（159 道食材通行的菜，人在外地也能照做）
- 📊 难度与用时排序
- 📖 点击菜卡查看完整材料清单与分步做法，部分菜谱含「做法一 / 做法二」变体
- 🎲 「今天吃什么」随机推荐
- 🍽 一键点菜：按人数（2–12 人）与是否喝酒自动搭配一桌菜，冷菜先上，荤素均衡、主料不重复
- 📱 响应式布局，桌面 / 平板 / 手机均适配
- 🔗 深链直达（如 `#recipe-15`）

## 本地运行

纯静态网站，零依赖。双击 `cixi-recipes.html`，或启动本地服务器：

```bash
cd cixi-recipes
python3 -m http.server 8899
# 浏览器访问 http://localhost:8899/
```

## 技术栈

原生 HTML / CSS / JavaScript + ECharts（本地资源，无外网依赖）。
